# Claude Skills — Academic

A collection of [Claude](https://claude.ai) skills for academic and study work: turning any topic into a deep, structured study guide, building an exhaustive reference "book" on a subject, and other study-support automations.

## Skills in this repo

| Skill | What it does |
|---|---|
| [`resume-university`](./resume-university) | Turns any topic into a deep, structured study guide (concept, why it matters, in-depth content, connections/mnemonics, checklist), with an optional study time-map, delivered as a PDF. |
| [`guide-automatic`](./guide-automatic) | Generates an exhaustive, encyclopedia-style reference work on any subject: full book structure (preface, table of contents, thematic chapters, glossary, references, index), then stays on as an interactive subject-matter expert. |
| [`reference-analysis`](./reference-analysis) | Structured analysis/critique of reference material or sources. |
| [`science-practice`](./science-practice) | Science-grounded study/practice support. |
| [`word-personalize`](./word-personalize) | Generates formatted Word documents following institutional/academic formatting specs (with an example spec included). |

## Install a skill

Download the `SKILL.md` (and any `references/`/`scripts/`/`assets/` folder) from the skill's subfolder and add it as a skill in Claude, or point Claude at this repo directly.

## Why these exist

Each skill automates a real piece of study work, not just a one-line prompt, so you get a repeatable, high-quality output instead of starting from scratch every time.
